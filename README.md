# Happy Farm — ฟาร์มสุขใจ

เกมทำฟาร์มสำหรับทดสอบบนมือถือและคอม: ปลูกผักและผลไม้ เลี้ยงหมู ซื้อเมล็ด เก็บเกี่ยว ขายผลผลิต และบันทึกเซฟในเบราว์เซอร์

## เล่นผ่านมือถือ
เปิด GitHub Pages หลังอัปโหลดไฟล์เกม โดยไปที่ Settings → Pages → Deploy from a branch → main / (root).

เกมแยกใหม่จากโปรเจกต์อื่นทั้งหมด ใช้ภาพ Kenney Tiny Farm CC0 ผ่าน GitHub (มีภาพ emoji สำรองเมื่อโหลดภาพไม่ได้)
